# VARN Brand Kit — v1.0

This folder contains the editable brand guide and starter assets based on the approved VARN visual direction.

## Included
- `VARN_Brand_Guide.docx` — editable brand standards document
- `VARN_Brand_Guide.pdf` — shareable, fixed-layout edition
- `assets/varn_logo_on_charcoal.svg` / `.png` — primary stacked lockup for dark surfaces
- `assets/varn_logo_on_bone.svg` / `.png` — primary stacked lockup for light surfaces
- `assets/varn_mark_*.svg` — mark-only vectors
- `assets/varn_app_icon.svg` / `.png` — square icon starter
- `assets/varn_design_tokens.css` — web design tokens and CSS defaults
- `assets/varn_moodboard_reference.png` — approved moodboard reference
- `assets/varn_original_logo_reference.png` — original generated logo image reference

## Core values
Charcoal `#0B0F14`; Night `#111820`; Steel Blue `#4B5B6B`; Fog `#A7B3BD`; Bone `#F4F3EF`; Sage `#7A8B7E`; Ink `#17212B`.

## Notes
The SVGs are clean starter vectors created to operationalize the selected concept; compare them with the original approved image before external release. Font recommendations are Space Grotesk for display and Inter for body, with Arial/sans-serif fallbacks. Confirm font licensing and verify trademark/domain availability separately before public launch.
